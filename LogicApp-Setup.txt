TAGGED VM WEEKDAY SCHEDULER - SETUP GUIDE
=======================================

The complete setup and operations guide is in README.md in this directory.
Open it in VS Code and use "Markdown: Open Preview" for formatted instructions.

The guide covers:
- Prerequisites, sign-in, provider registration and managed-identity permissions.
- Creating the resource group, Automation account, runtime, runbook and Logic Apps.
- Single-subscription setup: omit -VmSubscriptionId.
- All resource groups in that subscription: omit -VmResourceGroupName (the default).
- Optional cross-subscription setup in the same Entra tenant.
- Tagging VMs, preview testing, enabling live schedules and pausing safely.
- Existing-account setup, parameter reference, monitoring and troubleshooting.

Schedule: start at 08:00 and stop/deallocate at 19:00, Monday-Friday, UK GMT/BST.
No weekend runs. Deployment defaults to disabled schedules with DryRun=true.

Single subscription:
  -SubscriptionId identifies BOTH the hosting and VM subscription by default.
  -ResourceGroupName identifies the scheduling resource group.
  All VM resource groups are searched by default, filtering by the configured tag.
  Optionally supply -VmResourceGroupName to restrict the search to one group.
  Subscription-wide targeting grants the Automation identity VM permissions on
  the entire VM subscription; the runbook applies the tag filter.

Cross-subscription:
  Add -VmSubscriptionId to select a different VM subscription in the same tenant.

Deploy-VmSchedule.ps1 creates the complete solution. The raw ARM template at
infra\vm-schedule.json creates only the two Logic Apps.

Saving or reading the guide does not redeploy or enable any existing resources.
